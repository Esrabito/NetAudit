# NetAudit
Sistema para analizar redes corporativas, orientado a facilitar el diagnóstico para el técnico que lo utilice, aunque puede utilizarse en cualquier ámbito como por ejemplo doméstico.

## Estado

En desarrollo - versión 0.1

## Objetivo

Brindar al técnico un diagnóstico rápido y confiable del estado de una red local.

NetAudit:

- **Mide** conectividad, latencia, pérdida de paquetes y resolución DNS.
- **Calcula** una calificación general de la red (de A+ a F), indicando qué pruebas no pudieron realizarse.
- **Genera** un informe con los resultados y recomendaciones para diagnosticar fallas.

## Uso responsable

NetAudit debe utilizarse únicamente en redes y equipos que el usuario esté autorizado a evaluar.

No es una herramienta de escaneo agresivo: sus pruebas están diseñadas para obtener un diagnóstico sin afectar el funcionamiento de la red ni la disponibilidad de los dispositivos.
